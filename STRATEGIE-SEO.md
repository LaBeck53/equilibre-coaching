## PLANNING 3 MOIS

### MOIS 1 — Fondations techniques SEO

**Semaine 1-2 : Technique**
- [ ] Déposer le nom de domaine (ex: equilibre-coaching.fr)
- [ ] Héberger le site (OVH, Ionos ou Netlify)
- [ ] Configurer Google Search Console
- [ ] Configurer Google Analytics 4
- [ ] Soumettre le sitemap XML
- [ ] Vérifier Core Web Vitals (PageSpeed Insights > 85)
- [ ] Configurer le certificat SSL (HTTPS)
- [ ] Créer robots.txt

**Semaine 3-4 : On-page**
- [ ] Vérifier que chaque page a une meta title unique < 60 caractères
- [ ] Vérifier que chaque meta description est unique et < 160 caractères
- [ ] Ajouter des balises alt descriptives sur toutes les images
- [ ] Implémenter les données structurées Schema.org sur toutes les pages
- [ ] Créer une page sitemap.xml statique
- [ ] Créer le fichier robots.txt

**Actions locales**
- [ ] Créer/revendiquer la fiche Google Business Profile (anciennement Google My Business)
  - Catégorie : "Coach personnel" + "Service de formation"
  - Zones d'intervention : Normandie, Évreux, Paris
  - Photos professionnelles
  - Horaires, téléphone, lien site
- [ ] Inscrire sur Pages Jaunes, Mappy, Yelp (citations locales)
- [ ] Inscription sur l'annuaire ICF France

## AMÉLIORATIONS UX POUR LA CONVERSION

### Quick wins (à faire en priorité)
1. **Bouton "Appel gratuit" flottant** sur mobile — visible en permanence
2. **Pop-up de sortie** (exit intent) sur pages clés avec offre appel découverte
3. **Social proof permanent** — bandeau avec "200+ managers accompagnés" sous le nav
4. **Temps de réponse visible** — "Réponse sous 24h" sur la page contact
5. **Téléphone cliquable** (tel:) sur mobile dans le header

### Optimisations formulaire contact
- Réduire le formulaire à 4 champs max (nom, email, sujet, message)
- Ajouter une estimation de délai de réponse
- Confirmer l'envoi avec une page de remerciement dédiée (pour tracking Google Ads)

### Trust signals à renforcer
- Badges certifications (ICF, RNCP) visibles dans le header
- Nombre de clients/séances bien visible sur la home
- Logo ou mention des structures clientes (avec accord)
- Extrait vidéo de témoignage client (même 60 secondes)

### Performance mobile
- [ ] Vérifier que tous les CTA sont ≥ 44px de hauteur (cible tactile)
- [ ] Tester le formulaire de contact sur iPhone et Android
- [ ] S'assurer que la nav mobile ferme bien sur sélection
- [ ] Vérifier que le scroll est fluide sur toutes les sections
